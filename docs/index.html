01

Get started

Before you begin

You need a terminal, Node.js, and a model provider. Add other integrations only when you need them.

  • Node.js 20 or 22+ and npm. Check with node --version.
  • A model credential: an NVIDIA NIM API key, or an API key and base URL for an OpenAI-compatible Chat Completions service.
  • Internet access for npm installation and your model endpoint.

Optional extras: a Tavily key for web search, Chrome for /browser, Docker for the sandbox, and a Telegram bot for remote chat and scheduled delivery. /computer needs an interactive host desktop; on macOS, grant the permissions shown by its diagnostic report.

02

Get started

Install Sun2Agent

For everyday use, install globally, then launch it from the folder you want the agent to work in.

Terminal · recommended
npm install -g sun2agent
cd /path/to/your/project
sun2agent

To try it without a global installation, run npx sun2agent. To update a global installation later, run npm install -g sun2agent@latest. To use the latest repository code, clone and run locally:

Terminal · latest source
git clone https://github.com/snowhypers/Sun2Agent.git
cd Sun2Agent
npm install
npm start
Working directory matters. Sun2Agent treats the directory you launch from as the active workspace. Start it inside your project before asking it to edit files.
03

Get started

First run & configuration

Use /config to choose a provider and set optional services. Each topic is independent; select Done when you want to save.

  1. Provider and model: select built-in NVIDIA NIM or add a custom OpenAI-compatible provider.
  2. API key: paste your key into the hidden prompt. On later visits, press Enter to keep the saved key.
  3. Model: pick a listed NVIDIA model, or enter the exact model ID supplied by your custom provider.
  4. Optional services: turn LangSmith tracing, Tavily web search, memory, and Telegram on or off separately.
  5. Done: review the confirmation summary and return to chat.
Your first task
› Explain this project's structure and suggest the first test to run.

Saved credentials live in the owner-only ~/.sun2agent/config.json. Custom providers must support the OpenAI-compatible Chat Completions API; agent tool use also requires compatible tool calling.

04

Work with tools

Workspace files

File tools are available automatically. There is no /workspace step: launch from a project folder and describe the file task in plain language.

Try this

“Read the package scripts, add a focused test for the parser, then tell me which test command to run.”

Reads can run without approval. Writing files asks for approval for routine changes in the current prompt; deletion asks again. File access stays within the active workspace and protected credential files remain blocked.

Put project-specific guidance in AGENT.md at the workspace root. Use /agent to open or create it.

05

Work with tools

Web search

Web search is off by default. In /config, choose Web Search, enable Tavily, and save its API key. The agent can then use web_search for current facts and research questions.

Try this

“Find the latest Node.js release from the official release notes. Include its date and source URL.”

For time-sensitive answers, check the publication date and linked source. A search result is evidence to inspect, not a guarantee that a claim is current.

06

Work with tools

Browser automation

Run /browser to start Playwright MCP with an isolated Chrome profile. The browser stays disconnected until requested.

Example
/browser
› Open nodejs.org and show me the latest release notes.

The isolated profile is separate from your normal signed-in browser. Expect to sign in yourself if a site requires an account. Clicking, typing, dragging, and key presses require fresh approval; inspect the target before allowing a consequential action.

Browser vs computer: /browser controls an isolated web browser. It does not control your other desktop apps.
07

Work with tools

Computer control

/computer connects native desktop-control tools on demand. Unlike /browser, it operates your real host desktop, so watch the actions and approve each change carefully.

  1. Run /computer and confirm that you want real desktop access.
  2. Choose image support only if your selected model accepts images.
  3. Review the permission report. On macOS, Accessibility and Screen Recording may be needed; some actions ask for Automation permission.
  4. Ask for a narrow task, such as “Open VS Code and show its current window.”

Read-only checks need no approval. Opening or activating the same app shares one approval per prompt; clicks, typing, menu selections, and scripts still ask separately. Esc stops the active turn; Esc at an empty input disconnects /computer. It is unavailable inside the Docker sandbox.

The first connection can download its pinned MCP package and has a 30-second connection limit. A connected server does not guarantee every app is controllable.

08

Work with tools

Connect MCP servers

Use /mcp to edit ~/.sun2agent/mcp.json, connect one server, connect all, or disconnect. Sun2Agent supports local stdio servers and remote HTTP/SSE servers.

~/.sun2agent/mcp.json
{
  "mcpServers": {
    "research": {
      "type": "http",
      "url": "https://your-server.example.com/mcp",
      "telegramTools": ["search"]
    }
  }
}

The optional telegramTools list names remote read-only tools you explicitly allow in Telegram; without it, no MCP tools are exposed there. Local MCP servers, browser tools, computer tools, and approval-required actions are never offered to Telegram.

Trust boundary: a local MCP server can launch a program, and a remote server receives tool arguments. Add only servers you trust. Tool descriptions and “read-only” hints are not security guarantees.
09

Stay connected

Set up Telegram

Telegram lets one configured private chat reach your running agent. The CLI must stay open to receive and answer messages.

  1. In Telegram, open @BotFather, send /newbot, choose a name and username, and copy the bot token. Keep it private.
  2. Open your new bot and send /start so there is a chat to authorize.
  3. Find your numeric Telegram user/chat ID. You can inspect your bot’s getUpdates response after sending a message; in a private chat, use the matching message.chat.id and message.from.id. Do not share the token or paste the API response into a public issue.
  4. In Sun2Agent, run /config → Telegram, answer Yes to Connect Telegram?, then enter the bot token and numeric chat ID. Select Done.
  5. Keep Sun2Agent running and send your bot a question.
/start help/new fresh chat/stop abort current reply

Typing status appears before the response and the reply is edited as text arrives. Telegram does not receive local file, browser, or desktop control tools. Selecting “No” in configuration disables Telegram without deleting stored credentials.

10

Stay connected

Scheduled Telegram tasks

With Telegram configured, write a task containing three things: what to do, when, and once or daily. If a detail is missing or conflicts, Sun2Agent asks you to clarify.

Example
› Every day at 9 PM, summarize today's AI news and send it to Telegram.

It saves the schedule with the machine’s detected timezone and shows the complete result. Use /schedule to inspect jobs or confirm deletion. Only unattended read-only tasks are supported. The CLI must remain running for jobs to fire. On a VPS, verify that its timezone matches the time you expect.

Reliability note: a failed Telegram delivery remains scheduled for retry. If Telegram accepts a message immediately before a crash, a duplicate may be possible after restart.
11

Stay connected

Sessions, memory & Skills

A normal launch starts a fresh conversation. The footer estimates retained chat tokens; it does not show total provider usage or remaining model capacity.

Conversation

/new clears the current chat. /continue resumes an interrupted task from the current session snapshot, if available.

Saved task summary

/save drafts a short summary; nothing is saved until you approve it. Relevant summaries can help later tasks in the same workspace.

Memory

Enable memory in /config. /memory opens editable preferences in ~/.sun2agent/memory.md.

Project rules & Skills

AGENT.md holds project instructions. /skills lets you edit and select reusable instruction blocks from skills.md.

These sources are advisory context, not a way to override guardrails or tool approvals. The agent may propose a short lesson after a clear failure; choose Save or Discard.

12

Operate safely

Approvals & guardrails

Sun2Agent checks inputs and tool calls with command, network, filesystem, and output guards. Sensitive output is masked before it is kept in the conversation or shown to the model. These rules reduce risk but do not make arbitrary tools safe.

Prompt→Model proposes tool→Guards + approval→Tool runs

Read-only checks generally run without interruption. Routine changes can share one approval for that MCP server and prompt. Deletes, messages, scripts, purchases, account changes, and unknown actions require a fresh decision. Approvals do not carry into another prompt.

Your model provider receives the prompts and tool context needed to answer. Tavily, LangSmith, and Telegram receive data only when enabled or used. There is no built-in telemetry, but optional integrations have their own data policies.

13

Operate safely

Optional Docker sandbox

Enable Docker isolation if you want the whole agent to run in a container. Docker must be installed and running first. The agent will not silently fall back to host execution if Docker is unavailable.

Terminal
sun2agent sandbox enable
sun2agent sandbox status
sun2agent sandbox disable

The active project is mounted into the container as its workspace. Host desktop control with /computer is unavailable inside Docker; local host-integrated MCP servers may also need a different setup. Use /browser only if its browser dependencies are available inside the container.

Operate safely

Troubleshooting

The agent answers but does not call tools

Check that the selected model supports OpenAI-compatible tool calling. Confirm the relevant integration is connected (/browser, /computer, or /mcp). Try a precise task that names the desired action.

The model returns HTTP 429

The provider is rate-limiting your requests. Wait for its cooldown, reduce repeated prompts or tool loops, or select another model. Sun2Agent retries some transient model errors once; it does not override a long Retry-After.

Telegram reports a getUpdates conflict

Two running processes are polling the same bot token. Stop the other Sun2Agent instance, then restart one copy.

Browser or computer cannot connect

For /browser, check Chrome and the isolated browser startup. For /computer, inspect the permission report and remember it needs the host desktop, not Docker. First use may download the MCP package.

Scheduled message did not arrive

Keep Sun2Agent running, verify Telegram is connected, check the saved job with /schedule, and confirm the displayed timezone. A job cannot fire while the CLI is closed.
